# AESA Nagar — PHP + MySQL backend (local test → Hostinger live)

Same behaviour as the current site's backend: the four public forms save to a
database, and the admin panel lists every submission with CSV export. No
Firebase, no paid services — plain PHP 8 + MySQL, which is exactly what
Hostinger shared hosting gives you.

## What's inside

```
php-backend/
  index.php              health check + links (delete before going live if you like)
  config.php             database details + admin WhatsApp number
  schema.sql             all tables
  api/submit.php         one endpoint for all 4 forms, returns the wa.me link
  admin/login.php        sign in / first-account-becomes-admin
  admin/index.php        dashboard with tabs: Contact, Membership, Bhawan, Ads
  admin/export.php       CSV download
  lib/                   db + helpers (not web-accessible)
  uploads/               membership licence/photo uploads
```

## 1. Run it locally

Requirements: PHP 8.1+ and MySQL (XAMPP, MAMP, or Laragon include both).

1. Create the database:
   ```bash
   mysql -u root -p < php-backend/schema.sql
   ```
   (Or import `schema.sql` through phpMyAdmin.)
2. Open `php-backend/config.php` and set your local MySQL user/password.
3. Start PHP's built-in server:
   ```bash
   php -S localhost:8000 -t php-backend
   ```
4. Visit http://localhost:8000 — the database line should say **Connected**.
5. Visit http://localhost:8000/admin/login.php and create the first account.
   That first account automatically becomes the admin.
6. Test a form submission from the command line:
   ```bash
   curl -X POST "http://localhost:8000/api/submit.php?form=contact" \
     -H "Content-Type: application/json" \
     -d '{"name":"Test User","phone":"+919999999999","subject":"Hello","message":"Testing"}'
   ```
   You should get `{"ok":true,"id":1,"whatsapp":"https://wa.me/..."}` and the row
   should appear in the admin dashboard.

## 2. Point the frontend at it

Each form does one `fetch` and then opens the returned WhatsApp link:

```js
const res = await fetch("https://yourdomain.com/api/submit.php?form=contact", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name, phone, email, subject, message }),
});
const data = await res.json();
if (data.ok) window.open(data.whatsapp, "_blank", "noopener,noreferrer");
```

For the membership form send `FormData` instead of JSON (so the licence and
photo files upload) and set no `Content-Type` header — the browser handles it.

Field names per form:
- `contact`: name, phone, email, subject, message
- `membership`: name, phone, email, profession, licence_no, website, office_address, document (file), photo (file)
- `bhawan`: name, phone, email, event_type, event_date, guests, notes
- `advertise`: company, name, phone, email, package, message

## 3. Go live on Hostinger

1. hPanel → **Databases → MySQL Databases** → create a database and user. Copy
   the database name, username, password and host.
2. hPanel → **phpMyAdmin** → open your new database → **Import** → upload
   `schema.sql`. Delete the `CREATE DATABASE` and `USE` lines first, since
   Hostinger already created the database for you.
3. Edit `config.php` with those credentials, set `admin_whatsapp` to the real
   AESA number (digits only, e.g. `9198…`), and set `cors_origin` to your
   domain (e.g. `https://aesanagar.org`) instead of `*`.
4. hPanel → **File Manager** → upload the whole `php-backend` folder contents
   into `public_html` (or into `public_html/api-backend/` if you want the React
   site at the root — then your endpoint is `/api-backend/api/submit.php`).
5. Set folder permissions: `uploads/` needs to be writable (755 is fine).
6. Visit `https://yourdomain.com/admin/login.php` and create the admin account
   immediately, before anyone else can.
7. hPanel → **SSL** → make sure HTTPS is on and forced.

## Security notes

- Passwords are hashed with `password_hash`, sessions are HTTP-only, admin
  forms use CSRF tokens, all SQL uses prepared statements.
- Only the first signup can become admin; after that, signup is closed.
- `uploads/` cannot execute PHP, and file uploads are limited to PDF/JPG/PNG
  under 5 MB.
- Create extra admins by inserting a row into `admins` with a hash generated by
  `php -r 'echo password_hash("yourpassword", PASSWORD_DEFAULT);'`.
